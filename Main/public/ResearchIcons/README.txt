Place research item icons in this folder.

Recommended naming:
- Only create icons for the tier I / root node of each research chain.
- Tier II and Tier III nodes automatically reuse their tier I chain icon.
- Use that tier I research node id as the filename.
- Format: <node-id>.png

Examples:
- eco_tax_efficiency.png
- eco_industrial_output.png
- eco_agricultural_expansion.png
- mil_nuclear_research.png
- mil_barracks_i.png
- inf_warships.png

These files are loaded in-game at:
/ResearchIcons/<node-id>.png
